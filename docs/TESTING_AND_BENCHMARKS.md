## 1. Engineering Standards

- **Python (`3.12+` / `3.13`):** Strict typing on public APIs (`mypy --strict`), Ruff lint & format (`ruff check .`, `ruff format --check .`, line length `120`), Google-style docstrings, Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`, `refactor:`, `security:`).
- **Frontend (`dashboard/`):** **React 18 + Vite + JavaScript/JSX ONLY.** TypeScript (`.ts`/`.tsx`, `tsc`, TS ESLint plugins) is strictly prohibited unless reversed by an accepted ADR.

## 3. Continuous Integration Pipeline (`.github/workflows/ci.yml`)

Every push and PR to `main` / `develop` executes 7 jobs:
1. **`lint-and-format`:** `ruff check .` + `ruff format --check .`
2. **`type-check`:** `mypy --strict` across all core backend packages, `benchmarks`, `scripts`, and `tests/unit`
3. **`test-suite`:** Full `pytest tests/` coverage run + offline benchmark sanity check (`python -m benchmarks.runner --benchmark mmhal --limit 2`)
4. **`security-scan`:** `bandit -r gateway hrs_engine correction_agent shared workers -ll -ii`
5. **`frontend-test`:** `npm ci`, `npm test -- --run`, and `npm run build` in `dashboard/`, plus `npm test` in `sdk/js/`
6. **`infra-validate`:** `terraform fmt -check`, `terraform init -backend=false`, `terraform validate`, `helm lint`, `helm template`, and `docker compose config --quiet` (base + staging override)
7. **`docker-build`:** Multi-stage image build verification for `Dockerfile.gateway`, `Dockerfile.worker`, and `Dockerfile.dashboard`

## 4. Benchmarking & Scientific Integrity (`benchmarks/`)

MIRAGE distinguishes demonstration/synthetic tests from certified benchmark evaluations:
- **Runner CLIs:**
  - `python -m benchmarks.runner --benchmark <all|halueval|truthfulqa|factscore|mmhal> --limit N`
  - `python scripts/run_benchmarks.py --benchmark all --seed 42`
- **Provenance & Certification (`benchmarks/certification_guard.py`, `benchmarks/manifest.py`):**
  Tier 1 (curated demonstration suite) and Tier 2 (full-scale datasets) strictly track dataset versions, SHA-256 hashes, calibration ECE (`< 0.05` target), Mondrian conformal coverage, and explicit qualifiers on heuristic baseline proxies.
- **Publication Figures:** Vector SVGs generated by [`scripts/generate_figures.py`](../scripts/generate_figures.py) are stored in [`figures/`](figures/) (`ablation_study.svg`, `conformal_coverage.svg`, `interval_width_distribution.svg`, `latency_breakdown.svg`, `reliability_diagram.svg`, `roc_pr_curves.svg`).
